# S3 모니터링·시설관리 시각화 — 설계

- 날짜: 2026-09-28
- 로드맵: `2026-09-28-visual-overhaul-design.md` S3
- 목적: 텍스트 위주 관제 화면에 "한눈에 읽히는" 시각 요약 2개 + 밀도·잘림 정리
- 진행 방식: 사용자 "무중단" 지시 — 결정은 이 문서에 이유와 함께 기록

## 현재 상태

- 모니터링: 총계 줄 → 분야 카드 → 조치 필요 → 핵심 요소 → 층 × 분야 격자(텍스트 행) → 경보 통계. 차트 없음
- 격자 행: 이름 · 자산 태그 · 상태 4열 — 좁은 칸(210px)에서 이름이 `B1 주차장 …` 로 잘림. '이상만' 모드에서 층 16개 × 분야 5개에 "이상 없음" 80칸
- 자산 대장: 1,312행을 한 번에 렌더
- 뷰어 트리: 층 행 부제 `BuildingStorey 12.0…` 잘림 — 아이콘이 이미 층임을 말함

## 1. 건물 단면 히트맵 `StoreyStack.tsx`

- 위치: 모니터링 총계 줄 바로 아래 접이식 섹션 "건물 단면"(기본 펼침, 키오스크 포함)
- 동(building)별 열, 열 안은 층을 위(RF) → 아래(B2) 순서로 쌓은 행 — 건물 입면처럼 읽힘
- 행 = 층 이름 + 분야 5칸(소방·수송·설비·통신·전기, 팀 순서 고정) + 이상 건수
- 칸 색 = 상태 의미색만(시각 원칙: 색은 상태에만)
  - `crit`: 경보 있음 · `warn`: 장애·오프라인·절체·무전원·계측 위험 · `ok`: 요소 있음(무색 채움) · `none`: 요소 없음(빈 칸)
  - 판정 `cellLevel(rows, dead)` = 행들의 최소 `rank` 로 (0 → crit, ≤2 → warn) — 격자·조치 필요와 같은 기준, vitest
- 색 단독 의존 금지: 칸 hover 툴팁(`9F · 소방 — 경보 1 · 장애 0 · 요소 12`), 열 머리 분야 이름, 행 끝 이상 건수 숫자
- 클릭: 칸 → 분야 + 층 필터 후 격자로 스크롤, 층 이름 → 층 필터만

## 2. 24시간 발생 막대 `EventBars.tsx`

- 위치: 총계 줄 오른쪽 "마지막 이벤트" 앞, 24개 막대(시간당) 약 150×28px
- 데이터: 신규 `GET /api/models/{id}/monitor/timeline?hours=24` → `[{ at, alarms, faults }]` 24행(빈 시간도 0)
  - 발생 = 정상 → 이상(ALARM·FAULT) 전이 시점, `/monitor/stats` 와 같은 LAG 규칙
- 막대: 경보(crit) 위에 장애(warn) 누적, 2px 표면 간격, 폭 ≤ 5px, 기준선 1px
- 범례 대신 라벨 텍스트 `24시간 경보 N · 장애 N`(두 계열 → 식별은 글자로), 막대 hover 툴팁 `14시 — 경보 2 · 장애 1`
- 이력이 비면 기준선만 + `24시간 발생 없음`
- 테스트: `TimelineTests`(api) — 전이만 세고 반복 이상은 안 셈, 24칸 고정

## 3. 격자 밀도

- '이상만' 모드: 이상 없는 층 행 자체를 생략 + 격자 끝에 `이상 없는 층 N개 생략`
- 행에서 자산 태그 텍스트 제거 — 이름에 폭 양보. 태그는 행 title·객체 패널에 있음. 작업지시·결함·점검 지연 배지는 유지

## 4. 자산 대장 더 보기

- 필터 결과의 처음 100행 + `더 보기 (+100 · 남은 N)` 버튼. 필터가 바뀌면 100으로 리셋
- 가상 스크롤 제외 — 의존성 없이 100행 단위면 충분

## 5. 뷰어 트리 라벨

- 층 행 부제: `BuildingStorey 12.00m` → `EL +12.00` (클래스명은 아이콘이 대신)
- 그 외 공간 노드는 기존 유지

## 검증

- vitest: `cellLevel`
- api: `TimelineTests`
- 헤드리스: 모니터링(히트맵·막대·이상만 생략), 자산 대장 더 보기, 뷰어 트리. 상태 변경(`PATCH …/status`)으로 막대에 1건 생기는지 라이브 확인 후 원복

## 제외

- 계측값 추세 차트 확대(기존 트렌드 모달 유지)
- 시설관리 칸반 시각 변경 — 이미 정돈됨
