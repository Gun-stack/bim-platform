# S2 앱 셸 + 홈 — 설계

- 날짜: 2026-09-28
- 로드맵: `2026-09-28-visual-overhaul-design.md` S2
- 목적: 화면마다 제각각인 상단 내비를 하나로, 목록 화면을 "건물 운영 현황" 첫 화면으로
- 진행 방식: 사용자 "무중단" 지시 — 결정은 이 문서에 이유와 함께 기록, 검토는 완료 보고에서

## 현재 상태

- 내비: 화면마다 따로 — 뷰어 좌측 패널 첫 줄(`← 모델 목록 · 모니터링 · 시설관리 →`), 모니터링·시설관리 헤더 줄(`← 모델 목록` + 버튼), 지도 헤더
- 목록 `#/`(`App.tsx` `Models`): 큰 드롭존 + 7열 표. 화면 대부분이 빈 공간, 운영 상태(경보·작업지시) 없음
- 썸네일: 뷰어 선택 스냅샷(`sessionStorage`)만 — 방문자 브라우저 한정

## 1. 공통 상단 바 `Shell.tsx`

- 높이 44px, `T.bg.surface`, 하단 1px `T.bg.line`. 키오스크(`?kiosk`)에선 없음
- 왼쪽: 브랜드 `bim-platform`(→ `#/`)
- 모델 화면일 때 가운데
  - 모델 전환: 네이티브 `<select>`(READY 모델) — 같은 화면 유지, `?sel=` 은 버림(모델 간 GlobalId 무의미)
  - 화면 탭 3개: 3D 뷰어 · 모니터링 · 시설관리 — 현재 탭 강조, `?sel=` 유지(`selQ`)
- 오른쪽: 지도 · 운영 흐름 · 아키텍처
- 제거(중복): 뷰어 좌측 패널 첫 줄 내비, 모니터링·시설관리 헤더의 `← 모델 목록`·화면 이동 버튼, 지도 `← 모델 목록`
- 레이아웃: 바는 문서 흐름(비고정). 뷰어·지도는 `height: calc(100vh - 44px)`, 객체 패널(`ObjectDrawer`)은 `top: 44`
- 제외: 전역 경보 뱃지 — 세 화면 모두 첫 줄에 이상 건수가 이미 있고, 바에서 따로 폴링하면 중복 요청

## 2. 홈 `#/` — `Home.tsx`

- 머리 줄: 제목 "건물 운영 현황" + 합계(모델 · 요소 · 경보 · 장애 · 열린 작업지시) + `IFC 업로드` 버튼(파일 선택)
- 카드 그리드 `repeat(auto-fill, minmax(300px, 1fr))`, 최대 폭 1200
  - 썸네일 16:10 (없으면 건물 아이콘 자리표시)
  - 이름 · 스키마 · 요소 수 · 등록일
  - 운영 칩: 경보 N(crit) · 장애 N(warn) · 열린 작업지시 N — 0 이면 "정상"(무색, 시각 원칙: 정상은 색 없음)
  - 동작: `3D 뷰어`(주) · 모니터링 · 시설관리. 변환 중 = 진행 막대, 실패 = 오류 한 줄 + 재시도, 삭제 = 카드 hover 휴지통
- 업로드: 버튼 + 페이지 전체 드롭(끌어오면 반투명 안내막). 모델 0개면 큰 드롭존 빈 상태
- 합계 계산은 순수 함수 `summary(models)` (vitest)

## 3. 서버

- 모델 목록·단건 응답에 `alarms`·`faults`·`openWorkOrders` 추가 — `ModelController.SELECT` 에 LATERAL 집계
  - 경보·장애 = `Pset_BimStatus.Status` 가 `ALARM`·`FAULT`(웹 `isAbnormal` 과 같은 기준)
  - 열린 작업지시 = `work_order.status <> 'DONE'` (자산 → 모델)
- 썸네일: `GET`·`PUT /api/models/{id}/thumbnail` — MinIO `thumb/{id}.jpg`, `image/jpeg`, 256KB 상한(초과 400), 없으면 404. 모델 삭제 시 함께 삭제
  - 목록 응답엔 URL 을 넣지 않음 — 카드가 `<img src>` + `onError` 자리표시 (존재 여부 DB 열 없이)
- 테스트: 목록 집계 1개(`ModelSummaryTests`, Testcontainers). 썸네일은 테스트 컨테이너에 MinIO 가 없어 라이브 스모크로

## 4. 썸네일 생성 (뷰어)

- `Scene3D.thumbnail(w, h)`: 렌더러를 w×h(CSS 불변)로 바꾸고 홈 뷰로 맞춰 AO 켠 한 프레임 → 캔버스 복사 → 크기·카메라 원복. 한 태스크 안이라 화면 깜빡임 없음
- 시점: GLB 로드 2.5초 뒤(등장 연출 끝) 한 번 — `HEAD` 404 면 480×300 JPEG 을 `PUT`
- 첫 방문자가 만든 썸네일을 모두가 공유. 공개 데모(S4)는 쓰기 차단 전에 미리 생성

## 5. 검증

- vitest: `summary()`
- api: `ModelSummaryTests` — 경보 2·장애 1·열린 WO 1 시드 → 목록 수치
- 라이브: 썸네일 PUT → GET 200 `image/jpeg`, 삭제 후 404
- 헤드리스: 홈(썸네일·칩·합계), 세 화면 상단 바·탭 전환 `?sel=` 유지, 모델 전환, 뷰어 높이(하단 툴바 잘림 없음), 모니터링 객체 패널이 바를 가리지 않음
