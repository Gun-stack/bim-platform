# 01. AEC 산업 구조 — 누가 누구와 일하는가

> 기술보다 먼저. "AEC를 모른다"는 건 대부분 이 그림을 모르는 것이다.

## 핵심 질문

### 플레이어
- [ ] 발주처(Owner) / 설계사(Architect·Engineer) / 시공사(GC) / 전문건설(Sub) / 감리(CM) / 시설관리(FM) — 각각 프로젝트에서 무엇을 책임지는가?
- [ ] 설계사 안에서 건축(A) / 구조(S) / 기계·전기·배관(MEP) 분야는 어떻게 나뉘고 어떻게 협업하는가?
- [ ] 한국 실무에서 감리와 CM(건설사업관리)의 차이는?

### 생애주기
- [ ] 기획 → 설계(계획/기본/실시) → 시공 → 준공·인수인계(handover) → 운영(O&M) → 철거 — 각 단계에서 생산되는 핵심 문서/데이터는?
- [ ] 단계가 넘어갈 때 정보가 어떻게 전달되는가? (도면? 모델? 스프레드시트?) 어디서 정보가 유실되는가?
- [ ] 준공 인수인계 때 발주처가 실제로 받는 것들의 목록은?

### 발주 방식
- [ ] Design-Bid-Build vs Design-Build vs CM at Risk — 계약 구조에 따라 협업/데이터 흐름이 어떻게 달라지는가?
- [ ] 한국 공공 발주(조달청)에서 BIM이 의무화된 범위는?

## 참고 자료
