# 02. ISO 19650 — BIM은 모델이 아니라 정보관리 프로세스

> 이걸 알면 "우리 프로젝트가 BIM인가"에 스스로 답할 수 있다.

## 핵심 질문

### CDE (공통데이터환경)
- [ ] WIP → Shared → Published → Archive 상태 흐름 — 각 상태에서 누가 읽고 누가 쓸 수 있는가?
- [ ] 왜 "버전관리 없는 저장소"는 CDE가 아닌가? 개정(revision) 코드 체계는 어떻게 생겼는가?
- [ ] 상용 CDE 제품(Autodesk Construction Cloud, Trimble Connect 등)은 이 흐름을 UI로 어떻게 구현했는가?

### 요구와 응답
- [ ] EIR(발주처 정보요구사항)에는 구체적으로 뭐가 적히는가? 실제 EIR 샘플 하나 읽어보기
- [ ] BEP(BIM 실행계획)는 EIR에 어떻게 응답하는가? 사전(pre-contract) BEP와 사후 BEP의 차이는?
- [ ] MIDP/TIDP(정보 납품 계획)는 무엇을 언제 누가 내는지 어떻게 정의하는가?

### 정보 상세수준
- [ ] LOD(100~500) 와 ISO 19650의 LOIN(Level of Information Need)의 차이는?
- [ ] "기하 상세"와 "정보(속성) 상세"를 왜 분리해서 요구하는가?
- [ ] 설계 단계별로 같은 펌프가 LOD 200 → 400으로 어떻게 달라지는가? (구체 예시 하나 찾기)
